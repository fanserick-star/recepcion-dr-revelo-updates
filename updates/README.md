# Archivo histórico de actualizaciones de Recepción

Este directorio queda congelado desde la publicación consolidada 4.6.7.

Su contenido se conserva porque versiones antiguas, instaladores, diagnósticos o referencias de rollback pueden apuntar a estas rutas. No debe eliminarse ni reescribirse sin una auditoría específica de compatibilidad.

A partir de 4.6.7:

- no agregar nuevas carpetas de versión de Recepción aquí;
- no usar `updates/v...` como fuente del canal estable;
- desarrollar sobre `recepcion/app/`;
- conservar las versiones de rollback necesarias bajo `releases/reception/` o mediante el historial de Git.
