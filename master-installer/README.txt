INSTALADOR MAESTRO - CONSULTORIO DR. ARMANDO REVELO

Versión del instalador maestro: 1.0.0

Incluye:
- Recepción Launcher 1.0.12 (icono turquesa R + check)
- Historia Clínica Launcher 1.0.7 (icono azul/verde H + cruz)
- selector para instalar Recepción, Historia Clínica o ambos
- conserva data/, .env, bases locales, Excel, backups y configuraciones privadas
- cada launcher actualiza después su programa desde su canal oficial

Versiones de aplicación estables al preparar este instalador:
- Recepción 4.5.38
- Historia Clínica 1.3.24

IMPORTANTE:
Este instalador maestro v1.0.0 está diseñado para PCs que YA tengan la instalación base
en C:\Recepcion Dr Revelo y/o C:\Historia Clinica Dr Revelo.
No crea una base clínica nueva ni publica credenciales de Neon dentro del EXE.

Una instalación totalmente nueva se debe preparar con el paquete de bootstrap/configuración
privada correspondiente antes de usar este maestro.
